# SubScreen — 鸿蒙平板有线副屏

利用 USB 数据线将电脑内屏画面实时推送到鸿蒙平板，用作第二块真实工作区的镜像副屏。

## 功能特性

- **低延迟投屏**：由电脑端完成桌面捕获与 H.264 硬件编码，经 `hdc` 建立的 TCP 通道推流，平板端解码渲染。
- **实时状态反馈**：托盘运行 + 角落状态圆点，推流中显示绿点；断流具备自动重连与宽限期兜底。
- **按需分辨率**：提供 1920×1200@45 与 2560×1600@30（1:1）两套推流入口。
- **退出自动恢复**：停止或退出后自动恢复为电脑单屏。

## 使用流程

1. 用数据线连接平板与电脑，在平板端打开 SubScreen App。
2. 电脑端启动推流入口，点击「启动副屏」。
3. 窗口收进托盘即为推流中，右键托盘可停止 / 退出。

## 目录结构

| 路径 | 说明 |
|---|---|
| `pc/` | Windows 发送端：桌面捕获 + 编码 + 推流 + GUI/托盘 |
| `harmony/` | 鸿蒙平板接收端：TCP 收流 + H.264 硬解 + ArkTS 横屏 UI |

## 构建依赖

- **电脑端**：Visual Studio 2022（MSVC）+ Windows SDK 10.0.26100，`powershell -File build.ps1` 构建。
- **平板端**：DevEco Studio（SDK 6.1.0(23)），`hvigorw.bat assembleHap --mode module -p product=default --no-daemon` 构建。

## 已知问题

- Intel QSV 与 Microsoft DX12 编码器存在随帧的提交内存增长（QSV ≈4.7MB/帧、DX12 ≈1.7MB/帧），程序以「会话自动重建 + 进程级重启」两层策略兜底；存在数秒画面中断属预期行为。
- NVIDIA 编码器在 Optimus 混合输出机型上激活失败，暂未解决。
