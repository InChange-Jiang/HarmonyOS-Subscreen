# SubScreen — 把平板变成你的第二块屏幕

还在羡慕别人有双屏？用一根数据线，把鸿蒙平板变成你笔记本的**第二块真实工作区**，边写代码边看资料，不用再多花钱。

## 它是什么

- 把电脑屏幕画面实时投到平板，就像平板是"借来"的第二块显示器。
- 走数据线连接，低延迟、画质稳，适合长时间工作。
- 投屏后屏幕上还有个小圆点显示状态，绿点 = 正在推流，断流了它会自动重连，不用你管。

## 怎么用

1. 用数据线把平板插到电脑上。
2. 在平板上打开 SubScreen App。
3. 回到电脑，双击图标点一下「启动副屏」。
4. 窗口收进托盘，就这么简单。想停就右键托盘，选停止或退出。

> 停止或退出后，电脑会自动恢复成原来的单屏，不会搞乱你的桌面。

## 双端组成

- **`pc/`**：电脑端，负责抓取屏幕并推给平板。
- **`harmony/`**：平板端 App，负责接收并显示。

## 一些小提示

- 电脑端需要装 Visual Studio 2022 才能自己编译，日常使用直接跑现成的启动脚本即可。
- 平板端用 DevEco Studio 编译，装到平板上后正常联网都能用。
- 不想折腾编译的话，代码和脚本都整理好了，跟着目录里的说明走就行。

## 目前已知的小毛病

- 投屏时间很长时，部分 Intel / 微软自带的编码器会有内存占用缓慢增长，程序会自动定时重启一次来兜底（会卡个几秒），属正常现象。
- NVIDIA 显卡的独显直连模式可能没法启用硬件编码，暂未解决。
